# Velvet Pour Landing Page

A modern animated landing page for a cocktail bar built with React + TypeScript + GSAP.

This project was created while following a YouTube tutorial, but extended with improvements in TypeScript typing, semantic HTML, and animation adjustments.

## Features

- Smooth scroll animations using GSAP
- Responsive layout
- Semantic HTML structure
- TypeScript support
- Improved accessibility
- Small animation adjustments compared to the original tutorial
